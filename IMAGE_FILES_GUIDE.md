## 🔧 If Images Don't Show

### Check 1: File Names (Case Sensitive)
Make sure filenames match EXACTLY:
- ✅ `ai-translator.png` (lowercase, hyphen)
- ❌ `AI-Translator.png` (wrong case)
- ❌ `ai_translator.png` (underscore instead of hyphen)

### Check 2: File Location
Images must be in:
```
PortfolioWeb/images/portfolio-imgs/
```

### Check 3: File Extensions
- `ai-translator.png` (PNG format)
- `fast-share.jpg` (JPG format)
- `flash-light.jpg` (JPG format)

### Check 4: Browser Cache
Press `Ctrl + Shift + R` to hard refresh if images don't load.

### Quick Optimization:
